# computervision
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22885537.svg)](https://doi.org/10.5281/zenodo.22885537)
My first project in Lean, using Google Antigravity as part of my learning in computer vision.
The library is based on EMVA 1288, RGB, and YCbCr color specifications.
EMVA 1288's specification website: https://www.emva.org/standards-technology/emva-1288/
Installation is as simple as cloning the repo using git, so I will not instruct people again like the others. 
Lean is designed for stable version control, and since only the standard libraries are used here, there is no need to install anything else.
Lean's website: https://lean-lang.org/
